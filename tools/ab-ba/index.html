A short number theory proof

Solving \(a^b = b^a\) in Natural Numbers

A proof that the only solutions to \(a^b = b^a\) in natural numbers are the trivial pairs \((n, n)\) and the single nontrivial pair \((2, 4)\), given two independent ways: a calculus argument using the shape of \(\log(x)/x\), and a purely arithmetical derivation that needs nothing beyond the Bernoulli inequality.

1. Introduction

We look for all pairs of natural numbers \(a, b\) satisfying

\[ a^b = b^a. \]

  • Trivially, \((a,b) = (1,1)\), and more generally every pair \((n,n)\), is a solution.
  • Observe by inspection that \((2,4)\) is also a solution: \(2^4 = 16 = 4^2\).
  • The expression is symmetric in \(a\) and \(b\), so you will also get the solution \((4,2)\), and in general \((n_2, n_1)\) whenever \((n_1, n_2)\) is a solution.

Taking logarithms, rewrite the problem as

\[ a^b = b^a \;\Rightarrow\; b\log a = a \log b \;\Rightarrow\; \frac{\log a}{a} = \frac{\log b}{b}. \]

So solving \(a^b = b^a\) is the same as finding pairs \(a \ne b\) where the function \(\log(x)/x\) takes the same value twice.

2. Calculus: A Graphical Investigation

Sketch

\[ f(x) = \frac{\log x}{x}. \]

Its derivative is

\[ \frac{df(x)}{dx} = \frac{1}{x^2} - \frac{\log x}{x^2} = \frac{1 - \log x}{x^2}, \]

which is zero when \(\log x = 1\), that is \(x = e\). So the unique stationary point of \(f\) is \((e,\, 1/e)\), and it is a maximum: \(f\) rises on \((0, e)\) and falls on \((e, \infty)\).

Because \(f\) is strictly increasing before \(e\) and strictly decreasing after \(e\), any horizontal line \(y = c\) with \(0 < c < 1/e\) crosses the graph at exactly two points, one below \(e\) and one above \(e\). That is exactly the geometric picture of \(a^b = b^a\): two natural numbers \(a \ne b\) with \(f(a) = f(b)\) correspond to one point on each branch.

Observe that for any \(w > e\), the equation \(f(w) = f(x)\) forces \(x < e\), and the integer pair \((x, w) = (2, 4)\) satisfies this: \(f(2) = f(4) = \tfrac{1}{2}\log 2\). For any other \(w > 4\), requiring \(f(w) = f(x)\) forces \(x < 2\), and since the only natural number below \(2\) is \(1\), where \(f(1) = 0 \ne f(w)\) for \(w > 1\), there is no further natural-number match. This proves that all solutions to \(a^b = b^a\) are the trivial pairs \((n,n)\) together with \((2,4)\). \(\blacksquare\)

This graphical argument is short and convincing, but it leans on "observe that" and "convince yourself" at the key step. The next section makes the same conclusion airtight with pure algebra, no picture required.

3. Arithmetical / Algebraic Investigation

If either \(a\) or \(b\) equals \(1\), then \(a^b = b^a\) forces both to equal \(1\), giving the trivial pair \((1,1)\). In what follows, exclude this case, so \(a, b \ge 2\).

From \(a^b = b^a\),

\[ a = b^{a/b} = \left(\sqrt[b]{b}\,\right)^{a}. \]

Look at the sequence

\[ \sqrt[b]{b} = \sqrt{2},\ \sqrt[3]{3},\ \sqrt[4]{4},\ \sqrt[5]{5},\ \dots \]

and convince yourself that since \(a = \left(\sqrt[b]{b}\right)^{a}\) must be a natural number, it follows that:

  1. 1) \(a = b^k\), for some natural \(k\). Substituting into \(b^a = a^b\) gives

    \[ b^{(b^k)} = (b^k)^b = b^{bk}, \]

    which, since the bases match, means the exponents match too, or

2) \(kb = bk\), which yields, dividing both sides by \(b\), that

3) \(k = b^{k-1}\), for some natural \(k\).

If we find all solutions to (3), we are done.

A) if \(k = 1\), then from (1), \(a = b^k = b^1 = b\); that is, the trivial case.

B) if \(k \ne 1\), then from (3), \(b = k^{1/(k-1)}\).

Put \(m = k - 1\) and write \(b = k^{1/(k-1)}\) as

\[ b = (1+m)^{1/m}. \]

Use the Bernoulli inequality:

\[ (1+x)^p < 1 + px, \qquad \text{if } x > 0 \text{ and } 0 < p < 1. \tag{B} \]

4) \(\displaystyle b = (1+m)^{1/m} < 1 + m\cdot\frac{1}{m} = 2\), if \(0 < 1/m < 1\), by property (B).

Here we get three cases, on \(m = k - 1\):

Case m = 0

This was already discussed in (A): it gives back \(k = 1\), the trivial case.

Case m = 1

Property (B) required \(p = 1/m < 1\), but that fails when \(m = 1\), so inequality (4) does not apply here and must be checked directly. From (3):

\[ b = b^1 = 1 + 1 = 2, \]

further, according to (2),

\[ k = b^1 = 2, \]

and finally, according to (1),

\[ a = b^k = b^2 = 2^2 = 4. \]

Thus we recover the solution \((2, 4)\).

Case m > 1

Here \(k = m + 1 > 2\), so \(b = k^{1/(k-1)} > 1\), but inequality (4) forces \(b < 2\). So \(1 < b < 2\), yet \(b\) is a natural number, a contradiction. Thus, there are no more solutions.

\[ \displaystyle \text{The only solutions to } a^b = b^a \text{ in natural numbers are } (n,n) \text{ and } (2,4),\ (4,2). \]

This concludes the proof. \(\blacksquare\)

The two approaches agree, as they must, but they earn the result differently. The calculus route reads the answer off the shape of a single curve; the algebraic route derives it from a divisibility argument and one clean use of the Bernoulli inequality, with no picture needed at all.

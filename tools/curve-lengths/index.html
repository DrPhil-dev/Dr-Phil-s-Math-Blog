Pointwise limits vs. length limits

Curve Lengths in the Limit

The functions \(f_n(x) = x^n\) converge pointwise, on \([0,1]\), to a step function whose graph is a flat segment plus a single jump, a shape of total length 2. It is tempting to guess that the lengths of the curves \(f_n\) converge to that same value. They do, but not for the reason you might first assume, and the way it happens is worth seeing in detail.

1. Pointwise limit of \(f_n(x) = x^n\) on \([0,1]\)

Let \(X = [0,1]\) and define the sequence of functions

\[ f_n(x) = x^n, \qquad n \in \mathbb{N},\ 0 \le x \le 1. \]

Define the candidate limit

\[ f(x) = \begin{cases} 0, & 0 \le x < 1, \\ 1, & x = 1. \end{cases} \]

We show that \(f_n \to f\) pointwise on \([0,1]\).

1.1 Case \(0 \le x < 1\)

Fix \(x \in [0,1)\) and write \(x = 1 - \alpha\) with \(\alpha > 0\). Then \(x^n = (1-\alpha)^n\). Using the inequality \(1 - \alpha \le e^{-\alpha}\),

\[ 0 \le (1-\alpha)^n \le e^{-\alpha n} \xrightarrow[n\to\infty]{} 0. \]

Hence for each fixed \(x \in [0,1)\), \(\displaystyle \lim_{n\to\infty} f_n(x) = \lim_{n\to\infty} x^n = 0 = f(x)\).

1.2 Case \(x = 1\)

Here \(f_n(1) = 1^n = 1\) for every \(n\), so trivially \(\displaystyle \lim_{n\to\infty} f_n(1) = 1 = f(1)\).

Combining the two cases, \(\displaystyle \lim_{n\to\infty} f_n(x) = f(x)\) for all \(x \in [0,1]\): the sequence converges pointwise, but not uniformly, since the convergence gets arbitrarily slow as \(x \to 1^-\). That failure of uniform convergence is exactly what lets the arc length behave unexpectedly, as the rest of this piece shows.

2. Length of the graphs of \(f_n\)

For a differentiable function \(y = f_n(x)\), the arc length on \([0,1]\) is

\[ L_n = \int_0^1 \sqrt{1 + \bigl(f_n'(x)\bigr)^2}\,dx. \]

Since \(f_n'(x) = n x^{\,n-1}\), this becomes

\[ L_n = \int_0^1 \sqrt{1 + n^2 x^{\,2n-2}}\;dx. \]

3. Limit of the lengths \(L_n\)

We now compute \(\displaystyle \lim_{n\to\infty} L_n = \lim_{n\to\infty} \int_0^1 \sqrt{1 + n^2 x^{2n-2}}\,dx\). A quick heuristic says: for any fixed \(x < 1\), \(x^{n-1} \to 0\) rapidly, so the integrand tends to \(1\) there, contributing length \(1\) to the flat part. That leaves a boundary layer near \(x = 1\) to account for the other unit of length. Making this precise takes a bit more care, since the boundary layer shrinks in width exactly as fast as the integrand grows there.

3.1 Splitting the integral

Fix \(\delta \in (0,1)\) and split \(L_n\) into two parts:

\[ L_n = \int_0^{1-\delta} \sqrt{1 + n^2 x^{2n-2}}\;dx + \int_{1-\delta}^1 \sqrt{1 + n^2 x^{2n-2}}\;dx =: A_n(\delta) + B_n(\delta). \]

3.2 The bulk term \(A_n(\delta)\)

For \(0 \le x \le 1-\delta\) we have \(x^{n-1} \le (1-\delta)^{n-1}\), hence

\[ 0 \le n^2 x^{2n-2} \le n^2 (1-\delta)^{2n-2}, \]

and the right-hand side tends to \(0\) as \(n \to \infty\), since exponential decay beats the polynomial factor \(n^2\). So \(n^2 x^{2n-2} \to 0\) uniformly on \([0, 1-\delta]\), the integrand converges uniformly to \(1\), and we may pass the limit inside the integral:

\[ \lim_{n\to\infty} A_n(\delta) = \int_0^{1-\delta} 1\,dx = 1 - \delta. \]

\[ \boxed{\displaystyle \lim_{n\to\infty} A_n(\delta) = 1 - \delta.} \]

3.3 The boundary-layer term \(B_n(\delta)\)

Substitute \(x = 1 - t/n\), so \(dx = -\tfrac{1}{n}\,dt\), and as \(x\) runs from \(1-\delta\) to \(1\), \(t\) runs from \(n\delta\) down to \(0\):

\[ B_n(\delta) = \int_0^{n\delta} \sqrt{\frac{1}{n^2} + \Bigl(1 - \frac{t}{n}\Bigr)^{2n-2}}\;dt. \]

For each fixed \(t \ge 0\), \(\bigl(1 - t/n\bigr)^{n-1} \to e^{-t}\), so the integrand converges pointwise to \(e^{-t}\). A dominated-convergence argument on \([0,T]\), combined with a tail bound \(\int_T^{\infty} e^{-t}\,dt = e^{-T}\) that can be made arbitrarily small by choosing \(T\) large, upgrades this to

\[ \lim_{n\to\infty} B_n(\delta) = \int_0^{\infty} e^{-t}\,dt = 1. \]

\[ \boxed{\displaystyle \lim_{n\to\infty} B_n(\delta) = 1.} \]

So the boundary layer, despite shrinking to a single point in \(x\)-coordinates, contributes a full unit of arc length in the limit. This is the crux of the whole phenomenon: near \(x=1\) the slope \(f_n'(x) = nx^{n-1}\) blows up exactly fast enough, over an interval shrinking exactly fast enough, to sweep out a fixed amount of vertical rise.

3.4 Putting it together

Combining the two limits, for every fixed \(\delta \in (0,1)\):

\[ \lim_{n\to\infty} L_n = \bigl(1-\delta\bigr) + 1 = 2 - \delta. \]

Since this holds for all \(\delta \in (0,1)\), let \(\delta \to 0^+\) to conclude

\[ \boxed{\displaystyle \lim_{n\to\infty} L_n = 2.} \]

Geometrically, the limit curve is a horizontal segment from \((0,0)\) to \((1,0)\) (length 1) joined to a vertical segment from \((1,0)\) to \((1,1)\) (length 1), for a total length of exactly 2. The lengths \(L_n\) do converge to the length of the limit shape, just not by the naive argument of "take the length of the pointwise limit function," since that limit function \(f\) is not even continuous, let alone differentiable, and its graph as usually drawn (ignoring the vertical jump) has length only 1. It is the graph including the jump, the true geometric limit of the curves, that has length 2, and that is what \(L_n\) converges to.

This is a classic illustration of why pointwise convergence of functions does not imply convergence of associated geometric quantities like arc length: length is not continuous with respect to pointwise convergence, only with respect to stronger notions such as convergence in a Sobolev norm that also controls the derivative.

A First Mathematical Model

Maximum Number of Pieces Produced by Straight Line Cuts

What is the maximum number of pieces a circle, or pizza, can be divided into using n straight line cuts? A short derivation of the classic "lazy caterer's" formula, from first principles.

The question

What is the maximum number of pieces a circle, or pizza, can be divided into using \(n\) straight line cuts?

For example:

\[ \begin{aligned} 0 &\text{ cuts } \Rightarrow 1 \text{ piece},\\ 1 &\text{ cut } \Rightarrow 2 \text{ pieces},\\ 2 &\text{ cuts } \Rightarrow 4 \text{ pieces},\\ 3 &\text{ cuts } \Rightarrow 7 \text{ pieces},\\ 4 &\text{ cuts } \Rightarrow 11 \text{ pieces}. \end{aligned} \]

The natural question is: what is the formula for \(p(n)\), where \(p(n)\) denotes the maximum number of pieces produced by \(n\) straight cuts?

Beginning the pattern

If no cuts are made, there is exactly one piece: \(p(0) = 1\).

With one cut: \(p(1) = 2\).

With two cuts, the maximum occurs when the cuts intersect: \(p(2) = 4\).

With three cuts, each new cut should intersect all previous cuts, while avoiding passing through an existing intersection point. This gives \(p(3) = 7\).

With four cuts: \(p(4) = 11\).

A pattern emerges:

\[ \begin{aligned} p(1) - p(0) &= 1,\\ p(2) - p(1) &= 2,\\ p(3) - p(2) &= 3,\\ p(4) - p(3) &= 4. \end{aligned} \]

Hence, \(p(n) - p(n-1) = n\). Summing these differences gives \(p(n) - p(0) = 1 + 2 + 3 + \cdots + n\). Since \(p(0) = 1\),

\[ p(n) = 1 + \sum_{k=1}^{n} k. \]

Using the standard arithmetic series formula, \(1 + 2 + 3 + \cdots + n = \dfrac{n(n+1)}{2}\), we obtain

\[ p(n) = \frac{n(n+1)}{2} + 1 = \frac{n^2 + n + 2}{2}. \]

Verification

\[ \begin{aligned} p(0) &= 1,\\ p(1) &= 2,\\ p(2) &= 4,\\ p(3) &= 7,\\ p(4) &= 11,\\ p(20) &= 211. \end{aligned} \]

Note that \(p(20) = 211\), not \(212\).

Rigorous geometric argument

It is clear that \(n\) straight cuts divide the circle into a maximum number of regions if:

1. no two cuts are parallel, and
2. no three cuts are concurrent, meaning no three cuts pass through the same point.

Suppose that \(k\) cuts have already been drawn. Now draw the \((k+1)\)-st cut.

Because no two cuts are parallel, the new cut intersects each of the previous \(k\) cuts. Because no three cuts are concurrent, all of these intersection points are distinct.

Hence the new cut is divided into \(k+1\) separate parts. Each part passes through a different existing region of the circle, splitting that region into two pieces.

Therefore, the \((k+1)\)-st cut increases the total number of regions by exactly \(k+1\).

Starting from one region and repeatedly adding these increases gives

\[ p(n) = 1 + 1 + 2 + 3 + \cdots + n. \]

Thus,

\[ p(n) = 1 + \frac{n(n+1)}{2}. \]

Conclusion

The maximum number of regions produced by \(n\) straight cuts is

\[ p(n) = \frac{n(n+1)}{2} + 1 = \frac{n^2 + n + 2}{2}. \]

This maximum is achieved when:

• no two cuts are parallel, and
• no three cuts pass through the same point.

Generalisation challenge

A natural follow-up question is whether the cutting process can be optimised so that every piece has the same area, so each recipient gets an identical amount of pizza. It turns out this is a genuinely hard problem: the arrangement of cuts that maximises piece count is nothing like the arrangement needed for equal area, and solving for exact equal-area partitions with straight cuts quickly runs into cases with no clean closed-form answer. I am leaving this one as an open question rather than forcing a complicated answer into what is meant to be a simple, clean result.
